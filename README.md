# 🐍 Java Snake Game

A classic Snake game built with Java Swing.

## 🎮 Features

- Control the snake using the arrow keys.
- Eat apples to increase your score and grow longer.
- Score counter displayed on screen.
- Collision detection with walls and the snake's own body.
- Game Over screen when a collision occurs.
- Random apple placement.
- Simple graphical interface with a black background.

## 🕹️ Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move up |
| ⬇️ Down Arrow | Move down |
| ⬅️ Left Arrow | Move left |
| ➡️ Right Arrow | Move right |

## 🛠️ Built With

- Java
- Java Swing
- Java AWT
- `javax.swing.Timer` for game updates

## 🚀 How to Run

### Requirements

- Java Development Kit (JDK)

### Steps

1. Clone or download this repository.
2. Open a terminal in the folder containing `RealtimeCode.java`.
3. Compile the game:

   ```bash
   javac RealtimeCode.java
   ```

4. Run the game:

   ```bash
   java RealtimeCode
   ```
